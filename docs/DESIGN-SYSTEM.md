# Vastgoed Beheer B.V. — identité visuelle

La palette est définie dans `tailwind.config.ts` et `app/globals.css`.

| Usage | Couleur |
| --- | --- |
| Navigation, titres, actions principales | Bleu soutenu `#245B88` |
| Surfaces secondaires | Bleu brume `#EAF0F5` |
| Fond | Blanc `#FFFFFF` |
| Texte principal | Ardoise `#303A43` |
| Accents | Bleu clair `#B9DFFC` |

Les noms historiques des tokens restent disponibles pour préserver les composants existants. Les titres et contrôles utilisent Avenir Next, Segoe UI ou Arial sans téléchargement externe. Les erreurs restent rouges.

L’accueil utilise une grande photographie avec un voile sombre pour la lisibilité, une recherche blanche superposée au bas du visuel et des boutons bleus. Les villes forment une mosaïque photographique sur trois colonnes sur ordinateur, deux sur tablette et une sur mobile. Les cartes immobilières privilégient les photos et les prix ; les commentaires affichent les 50 noms fournis. Les couleurs couvrent également les pages internes, l’administration, le favicon et les modèles d’e-mails. Les mouvements respectent `prefers-reduced-motion`.

Les photos, prix, formulaires, requêtes Supabase, paiements et mécanismes d’authentification sont conservés. Les vérifications de cette version sont rapportées séparément dans la conversation ; les anciens contrôles visuels ne valident pas cette nouvelle présentation.
